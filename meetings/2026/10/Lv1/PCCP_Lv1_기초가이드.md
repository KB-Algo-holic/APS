## 1. 배열 순회·인덱스

### 언제 의심할까?

원소를 순서대로 보며 합·최댓값·조건에 맞는 값을 구하거나, 직전 원소와 비교한다. 특별한 알고리즘 없이 한 번의 순회로 해결되는 경우가 많다.

### 기본 사고

- 인덱스 범위는 `0~N-1`이다. `a[N]`은 범위 밖이다.
- ‘몇 번째’는 보통 1부터, 배열 인덱스는 0부터 시작한다.
- 연속 중복 제거는 **전체 중복 제거와 다르다**. `[1,1,2,1]`의 연속 중복 제거 결과는 `[1,2,1]`이다.
- 결과 개수가 미정이면 리스트에 모은 뒤 필요한 반환 형태로 바꾼다.

```text
result = 빈 리스트
for x in 입력:
    if result가 비어 있거나 마지막 값이 x와 다름:
        result에 x 추가
```

순회 O(N), 결과 저장 공간은 최대 O(N)이다.

### 자주 하는 실수

첫 원소에서 `a[i-1]`을 조회한다 / 홀수·짝수 길이의 가운데 위치를 혼동한다 / 순서를 유지해야 하는데 Set이나 정렬을 사용한다.

### 혼자 풀어보기

- 🟢 [가운데 글자 가져오기](https://school.programmers.co.kr/learn/courses/30/lessons/12903): 홀수는 한 글자, 짝수는 두 글자. 길이 1·2부터 확인한다.
- 🟡 ★ [같은 숫자는 싫어](https://school.programmers.co.kr/learn/courses/30/lessons/12906): 연속 중복만 제거한다. 한 번의 순회로 해결하자.

## 2. 문자열 처리

### 언제 의심할까?

대소문자 구분, 특정 문자 개수, 단어 치환, 문자열과 숫자의 변환이 등장한다. 먼저 **문자 단위인지, 단어 단위인지** 구분하자.

### 기본 사고

대소문자를 무시하는 문제라면 한쪽으로 통일하고 처리한다. 개수 비교는 카운터 두 개면 충분하다. 정해진 단어 10개를 치환하는 문제라면 복잡한 파서를 만들기 전에 내장 치환 함수로 가능한지 살핀다.

```text
pCount = 0, yCount = 0
for ch in 문자열을 소문자로 변환한 결과:
    if ch == 'p': pCount += 1
    if ch == 'y': yCount += 1
return pCount == yCount
```

문자열 한 번 순회는 O(L). 반복 치환은 치환 대상 개수와 문자열 길이를 함께 고려한다. 대상이 10개로 고정된 문제에서는 단순한 접근으로 충분할 수 있다.

### 자주 하는 실수

- 변환·치환 함수의 반환값을 저장하지 않는다. 원래 문자열이 자동으로 바뀐다고 생각하지 말자.
- JS의 `replace`에 문자열을 전달하면 첫 일치만 바뀌는 점을 놓친다. 전체 치환에는 `replaceAll` 등을 사용한다.
- 문자열 숫자와 실제 숫자를 혼동한다. 예: JS에서 `'1'+2`는 `'12'`다.
- 조건에 없는 공백 제거·대소문자 통일을 임의로 한다.

### 혼자 풀어보기

## 3. Map·Set — 개수와 종류 구분

### 언제 의심할까?

‘서로 다른 종류’, ‘중복’, ‘누가 몇 번 등장했는가’가 나온다.

| 필요한 정보 | 사용할 것 | 예 |
|---|---|---|
| 존재 여부·종류 수 | Set | 서로 다른 번호 개수 |
| 같은 값이 등장한 횟수 | Map | 동명이인 포함 참가자 수 |
| 작은 정수 범위의 개수 | 빈도 배열 | 0~9의 등장 횟수 |

### 기본 사고

```text
for name in 참가자:
    count[name] = count.get(name, 0) + 1
for name in 완주자:
    count[name] -= 1
남은 개수가 양수인 이름을 찾기
```

해시 조회·추가는 보통 평균 O(1)로 분석한다. 입력 N개를 처리하면 일반적으로 평균 O(N), 공간 O(서로 다른 키 수)다. 문자열 키의 길이 비용도 있을 수 있다.

### 자주 하는 실수

동명이인이 있는데 Set을 사용한다 / 없는 키를 조회하고 바로 더한다 / 종류 수와 선택 가능한 개수를 혼동한다 / Java의 문자열·Integer를 참조 비교로 판정한다.

## 4. 정렬·정렬 후 순회

### 언제 의심할까?

K번째 값, 작은 값부터 선택, 특정 기준의 순서가 등장한다. 정렬하면 조건 판단이 단순해질 수 있다.

### 기본 사고

K번째수는 **구간 복사 → 정렬 → K번째 조회**로 나눈다. 예산은 작은 요청부터 선택하면 같은 개수를 고를 때 필요한 총액을 최소화할 수 있다.

```text
요청 금액 오름차순 정렬
used = 0, count = 0
for cost in 요청 금액:
    if used + cost > budget: break
    used += cost
    count += 1
```

정렬 O(N log N), 이후 순회 O(N). ‘정렬 후 선택’이 항상 정답인 것은 아니며, 예산 문제는 **모든 지원 건을 같은 1건으로 세고 요청액을 전액 지급하는 조건** 덕분에 작은 금액부터 선택할 수 있다.

### 자주 하는 실수

- 원래 배열을 정렬해서 이후 요청에서 원본 순서를 잃는다. 구간별 계산이면 복사본을 사용한다.
- 구간 양 끝 포함 조건을 언어의 slice/substring 범위와 혼동한다.
- JS 숫자 배열에 비교 함수 없는 `sort()`를 사용한다.
- 1부터 시작하는 k를 그대로 배열 인덱스로 사용한다.

### 혼자 풀어보기

- 🟢 ★ [K번째수](https://school.programmers.co.kr/learn/courses/30/lessons/42748): 지문의 `[i,j]`는 양 끝 포함, 배열은 0부터 시작한다.
- 🟡 [예산](https://school.programmers.co.kr/learn/courses/30/lessons/12982): 작은 요청부터 선택하는 이유와 예산이 딱 맞는 경우를 설명한다.

**확인:** 정렬 때문에 사라지면 안 되는 정보가 있는가? 동률·정확히 같은 경계를 처리했는가?

## 5. 기초 구현·규칙 시뮬레이션

### 언제 의심할까?

특정 규칙을 반복 적용하거나, 사람별 점수·현재 위치·최댓값을 갱신한다. 규칙이 길어 보여도 **상태와 갱신 조건**으로 나누면 단순해질 수 있다.

### 기본 사고

- 규칙이 반복되면 `i % 패턴 길이`로 현재 항목을 찾는다.
- 사람마다 다른 값은 배열·변수로 따로 관리한다.
- 동률이면 모두 반환하는지, 한 명만 반환하는지 확인한다.
- 같은 조건을 여러 번 다룬다면 표현을 통일한다. 예: 명함마다 긴 변·짧은 변으로 정리.

```text
사람별 점수를 0으로 초기화
for i = 0 .. 정답 개수-1:
    for person in 사람들:
        if pattern[person][i % 패턴 길이] == answers[i]:
            score[person] += 1
최고 점수를 구하고 같은 점수인 사람 모두 반환
```

사람 수가 상수면 O(N). ‘이중 반복’이라도 내부 반복 크기를 함께 보자.

### 자주 하는 실수

반복 패턴의 길이를 잘못 쓴다 / 최고 점수 한 명만 반환한다 / 최댓값 초기화를 입력 범위와 맞추지 않는다 / 지문 규칙을 한꺼번에 구현하다 조건을 빠뜨린다.

### 혼자 풀어보기

- 🟢 [모의고사](https://school.programmers.co.kr/learn/courses/30/lessons/42840): 반복 패턴과 점수 계산, 동률 처리, 반환 순서를 연습한다.
- 🟡 ★ [최소직사각형](https://school.programmers.co.kr/learn/courses/30/lessons/86491): 각 명함의 긴 변·짧은 변을 통일해 각각의 최댓값을 구한다. 회전을 일일이 조합하지 않아도 된다.

**확인:** 규칙 하나당 코드의 어느 조건·변수가 대응하는지 짚을 수 있는가?

## 오늘의 실습·시험 전 체크리스트

**오늘의 추천 순서:** 같은 숫자는 싫어 → 완주하지 못한 선수 → K번째수 → 최소직사각형. 문자열이 약하면 숫자 문자열과 영단어를 추가한다. ★ 문제는 총 5개이며, 시간이 부족하면 이 문제부터 풀자. 나머지는 자습으로 보완한다.

| 단계 | 확인할 것 |
|---|---|
| 읽기 | 반환 타입, 원래 순서, 중복, 동률 규칙 |
| 설계 | 저장할 상태, 반복 범위, 초기값 |
| 구현 | 인덱스 범위, 없는 키, 문자열·숫자 변환 |
| 검증 | 최소 입력, 모두 같은 값, 조건 불만족, 정확히 경계인 값 |
| 제출 | 마지막 항목 처리, 불필요한 출력, 반환 형식 |

**시간 사용:** 5분 정도 풀이를 정리하고 15~20분 구현한다. 막히면 예제를 더 작게 만들어 손으로 계산한다. 해설을 봤다면 다음 날 자기 언어로 다시 구현한다. 첫 문제의 번호만 보고 쉽다고 단정하지 말고 실제 조건과 제한사항을 확인하자.

**출처:** 2026.10.06 프로그래머스 공식 문제 페이지를 확인했으며, 각 문제명에 원문 링크를 연결했다. 학습 순서와 풀이 포인트는 CoP 실습 목적의 편집 판단이다. 일부 문제는 앞서 만든 Lv.2 대비 가이드와 겹치며, 기초 복습과 유형 연결에 활용한다.

## 마지막 페이지. Java / Python / JavaScript 치트시트

Java는 `import java.util.*;`을 전제로 한다. `s`는 문자열, `a`는 배열/리스트다. 범위 복사의 `l`은 포함, `r`은 미포함이다.

| 작업 | Java | Python | JavaScript |
|---|---|---|---|
| 배열/리스트 길이 | `a.length` / `list.size()` | `len(a)` | `a.length` |
| 문자열 길이 | `s.length()` | `len(s)` | `s.length` |
| 문자 조회 | `s.charAt(i)` | `s[i]` | `s[i]` |
| 부분 문자열 `[l,r)` | `s.substring(l,r)` | `s[l:r]` | `s.slice(l,r)` |
| 소문자 변환 | `s.toLowerCase()` | `s.lower()` | `s.toLowerCase()` |
| 단어 전체 치환 | `s.replace(old,newText)` | `s.replace(old,new)` | `s.replaceAll(old,newText)` |
| 문자열 → 정수 | `Integer.parseInt(s)` | `int(s)` | `Number(s)` |
| 숫자 → 문자열 | `String.valueOf(x)` | `str(x)` | `String(x)` |
| 결과에 추가 | `list.add(x)` | `result.append(x)` | `result.push(x)` |
| 숫자 오름차순 | `Arrays.sort(a)` | `a.sort()` | `a.sort((x,y)=>x-y)` |
| 구간 복사 `[l,r)` | `Arrays.copyOfRange(a,l,r)` | `a[l:r]` | `a.slice(l,r)` |
| Set 생성 | `new HashSet<Integer>()` | `set()` | `new Set()` |
| Set 추가/크기 | `set.add(x)` / `set.size()` | `st.add(x)` / `len(st)` | `st.add(x)` / `st.size` |
| Map 생성 | `new HashMap<String,Integer>()` | `{}` | `new Map()` |
| 빈도 증가 | `m.put(k,m.getOrDefault(k,0)+1)` | `m[k]=m.get(k,0)+1` | `m.set(k,(m.get(k) ?? 0)+1)` |
| 빈도 조회(기본값 0) | `m.getOrDefault(k,0)` | `m.get(k,0)` | `m.get(k) ?? 0` |
| Map 순회 | `for (Map.Entry<String,Integer> e : m.entrySet())` | `for k,v in m.items():` | `for (const [k,v] of m)` |
| 최댓값 두 개 비교 | `Math.max(x,y)` | `max(x,y)` | `Math.max(x,y)` |
| 양수 정수 나눗셈 | `x / y` (정수 타입) | `x // y` | `Math.floor(x/y)` |

### 딱 기억할 주의점

- **Java:** 문자열 비교는 `equals`. `List<Integer>`를 `int[]`로 반환하려면 크기만큼 배열을 만든 뒤 반복문으로 옮길 수 있다. 큰 합·곱은 long, 곱셈 전부터 형변환한다. 문자열을 많이 이어 붙일 때는 StringBuilder.
- **Python:** `a.sort()`는 반환값이 None이므로 `a = a.sort()`로 쓰지 않는다. 새 정렬 리스트가 필요하면 `sorted(a)`. `set()`은 빈 Set, `{}`는 빈 dict다.
- **JS:** 숫자 정렬 비교 함수 필수. `sort()`는 원본 배열을 바꾼다. 문자열 숫자를 더하기 전에 숫자로 변환한다. Number의 안전 정수 범위는 ±(2⁵³−1)이다.
